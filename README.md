# Apple Keyboard Lang Switch by Tellarion

**tellarion.dev**

Переключение языка в Windows по **Command + Space** (на Apple-клавиатуре это **Win + Пробел**), как на macOS.

## Требования

- Windows 10 / 11
- Apple-клавиатура (клавиша Command = Win)
- Два и более языка в системе: **Параметры → Время и язык → Язык и регион**

## Файлы

| Файл | Описание |
|------|----------|
| `start.bat` | Запуск переключения языка в фоне |
| `stop.bat` | Остановка скрипта |
| `lang-switch.ps1` | Основной скрипт перехвата Win+Space |
| `run-hidden.vbs` | Скрытый запуск PowerShell без окна |
| `lang-switch.pid` | Служебный файл с PID процесса (создаётся автоматически) |

## Быстрый старт

1. Дважды кликните **`start.bat`**
2. Нажмите **Command + Space** — язык переключится
3. Для остановки запустите **`stop.bat`**

## Автозагрузка

1. `Win + R` → `shell:startup` → Enter
2. Скопируйте ярлык на `start.bat` в открывшуюся папку

## Как это работает

- Скрипт перехватывает сочетание **Win + Space** через low-level keyboard hook
- Язык переключается через `WM_INPUTLANGCHANGEREQUEST`
- Отпускание Win после сочетания блокируется, чтобы не открывалось меню «Пуск»
- `start.bat` отключает **Alt + Shift** для смены языка, чтобы не было конфликтов

## stop.bat

Останавливает фоновый процесс переключения языка:

- Завершает процесс по PID из `lang-switch.pid`
- Дополнительно ищет и закрывает все экземпляры `lang-switch.ps1`

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Язык не переключается | Добавьте второй язык в настройках Windows |
| Открывается меню «Пуск» | Запустите `stop.bat`, затем снова `start.bat` |
| Скрипт уже запущен | `stop.bat` → `start.bat` |
| Win «залип» | Один раз нажмите и отпустите Win, или перезагрузите ПК |
